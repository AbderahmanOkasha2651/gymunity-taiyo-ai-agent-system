# Run TAIYO Orchestrator with Python

This example shows how a backend service could call the **TAIYO Orchestrator Agent** using the Azure AI Foundry Python SDK.

In the planned GymUnity architecture, the backend should call the Orchestrator first.  
The Orchestrator then routes the request to the correct specialized agents.

---

## Purpose

This example shows how to:

- Connect to an Azure AI Foundry project
- Load the TAIYO Orchestrator Agent
- Create a thread
- Send a user message
- Run the agent
- Read the response

---

## Environment Variables

Do not hardcode project endpoints or agent IDs directly in public repositories.

Use environment variables instead:

```bash
AZURE_AI_PROJECT_ENDPOINT="https://your-foundry-resource.services.ai.azure.com/api/projects/your-project"
TAIYO_ORCHESTRATOR_AGENT_ID="your-orchestrator-agent-id"
```

---

## Python Example

```python
import os

from azure.ai.projects import AIProjectClient
from azure.identity import DefaultAzureCredential
from azure.ai.agents.models import ListSortOrder


project = AIProjectClient(
    credential=DefaultAzureCredential(),
    endpoint=os.getenv("AZURE_AI_PROJECT_ENDPOINT")
)

agent = project.agents.get_agent(
    os.getenv("TAIYO_ORCHESTRATOR_AGENT_ID")
)

thread = project.agents.threads.create()
print(f"Created thread, ID: {thread.id}")

message = project.agents.messages.create(
    thread_id=thread.id,
    role="user",
    content="Hello Agent"
)

run = project.agents.runs.create_and_process(
    thread_id=thread.id,
    agent_id=agent.id
)

if run.status == "failed":
    print(f"Run failed: {run.last_error}")
else:
    messages = project.agents.messages.list(
        thread_id=thread.id,
        order=ListSortOrder.ASCENDING
    )

    for message in messages:
        if message.text_messages:
            print(f"{message.role}: {message.text_messages[-1].text.value}")
```
